多路直播牆
使用說明與已知限制（提案前請先看過）
  1. 不能用滑鼠雙擊 HTML 檔開啟。file:// 不會送出 Referer， YouTube 的嵌入播放器會一律回錯誤碼 153 拒絕播放。請用同資料夾裡的 啟動直播廣場.cmd 開啟 —— 它會起一個本機伺服器並自動開瀏覽器， 再把網址改成 live-wall.html 即可。
  2. 小紅書、抖音的直播無法嵌入。這兩個平台沒有開放公開的嵌入方式，播放網址是簽章 token 加 Referer 鎖定，第三方網頁無法合法播放。這頁只能放 YouTube 直播。
  3. 網址格式。支援 youtube.com/watch?v=…、youtu.be/…、 youtube.com/live/…，或直接貼 11 碼影片 ID。
  4. 頻道網址（/@帳號、/channel/UC…）不能用。 YouTube 已經不支援「自動播出該頻道目前直播」的嵌入方式 （embed/live_stream?channel=… 實測一律回「無法播放這部影片」）。 取得可用網址的做法：開 youtube.com/@帳號/live，等直播載入後從網址列複製 watch 網址。
    因此預設清單裡的影片 ID 遲早會失效 —— 那一格會自己顯示錯誤與說明， 照上面的步驟換一條新網址即可。提案當天建議先開一次確認每一路都還活著。
  5. 自動播放一定是靜音起播（瀏覽器政策），且同一時間只有一格能有聲音 — 點該格的 🔊 切換。若整頁都不自動播，先按一次頂部的「▶ 全部播放」。
  6. 頻道主可以自行關閉嵌入播放。遇到時該格會蓋上錯誤說明與「在 YouTube 開啟」連結 （錯誤碼 101/150 就是這種）。這個沒有繞路辦法，只能換一路。
  7. 同時跑很多個播放器很吃 CPU 與頻寬。展示時建議 2×2 或 3×3； 4×4 在一般筆電上可能會頓。
  8. 設定存在瀏覽器的 localStorage。換電腦或換瀏覽器不會跟著走 — 要搬到別台，用「⚙ 設定」匯出 JSON 再到那台匯入。
