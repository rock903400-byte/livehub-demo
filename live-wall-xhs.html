使用說明與已知限制（提案前請先看過）
  1. 不能用滑鼠雙擊 HTML 檔開啟。file:// 不會送出 Referer， YouTube 的嵌入播放器會一律回錯誤碼 153 拒絕播放。請用同資料夾裡的 啟動直播廣場.cmd 開啟 —— 它會起一個本機伺服器並自動開瀏覽器。 要給客戶自己點連結看的話，把這些檔案丟上 GitHub Pages 或任何靜態主機（https）也可以。
  2. 觀看數與讚數是示意數字。頁面上每張卡片的觀看人數、讚數都是依影片 ID 產生的 固定假資料，只為了讓版面看起來完整，不是真實數據。對客戶展示時請說明這點。
  3. 直式卡片會裁掉畫面左右兩側。YouTube 嵌入是 16:9，這裡的卡片是直式 3:4， 用放大裁切來填滿，所以新聞台的跑馬燈、台標可能被切掉。點進大畫面看的是未裁切的完整 16:9。
  4. 小紅書、抖音的直播無法嵌入。這兩個平台沒有開放公開的嵌入方式，播放網址是簽章 token 加 Referer 鎖定，第三方網頁無法合法播放。這頁的視覺是小紅書風格，內容來源只能是 YouTube。
  5. 網址格式。支援 youtube.com/watch?v=…、youtu.be/…、 youtube.com/live/…，或直接貼 11 碼影片 ID。
  6. 頻道網址（/@帳號、/channel/UC…）不能用。 YouTube 已經不支援「自動播出該頻道目前直播」的嵌入方式。取得可用網址的做法：開 youtube.com/@帳號/live，等直播載入後從網址列複製 watch 網址。
    因此預設清單裡的影片 ID 遲早會失效 —— 那張卡片會自己顯示錯誤與說明。 提案當天建議先開一次確認每一路都還活著。
  7. 自動播放一定是靜音起播（瀏覽器政策）。同一時間只有一路能有聲音 —— 點卡片右上角的喇叭切換，或點進大畫面自動開聲音。
  8. 捲出畫面的卡片會自動暫停，捲回來再繼續，避免同時跑太多播放器把電腦拖垮。
  9. 頻道主可以自行關閉嵌入播放（錯誤碼 101/150），遇到時該卡片會顯示說明。 這個沒有繞路辦法，只能換一路。
  10. 設定存在瀏覽器的 localStorage。換電腦不會跟著走 —— 用右下角 ＋ 面板裡的「匯出設定」搬過去。
